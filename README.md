# Personal Portfolio 

Welcome to my personal portfolio project! This is a clean, responsive, and interactive portfolio built to showcase my skills, projects, and experience.

##  Technologies Used
- **HTML5** for structure
- **CSS3** for styling and animations
- **JavaScript (ES6+)** for interactive elements

##  Getting Started

To run this project locally, follow these simple steps:

1. Clone this repository:
   ```bash
   git clone https://github.com/Vashu102004/vashu-portfolio.git
   ```
2. Navigate into the directory:
   ```bash
   cd vashu-portfolio
   ```
3. Install dependencies (optional, for local development server):
   ```bash
   npm install
   ```
4. Run the development server:
   ```bash
   npm run dev
   ```
5. Open your browser and visit the local server link (e.g., `http://127.0.0.1:8080`) to view the portfolio.

*(Alternatively, you can just open `index.html` directly in your browser without any setup!)*

##  Features
- Fully responsive design (Mobile-friendly)
- Smooth scrolling and animations
- Interactive sections for About, Skills, and Projects
